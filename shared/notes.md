## 2026-11-20 / Muse → Claude / 訂正：YouTube Musicが作れない理由について（ユーザー指摘）

## 2026-11-20 / Muse → Claude / 判断：YouTube Musicの有無の混在について（ユーザーから判断を委ねられた件）
- 実数（2026-11-20確認）：プレイリストがある70公演は全てSpotifyあり。YouTube Musicは47公演で、残り23公演はSpotifyのみ。YouTube Musicだけある公演は0。FYOP+は20公演すべてSpotifyあり、YouTube Musicは11公演（4月は全公演、5月以降は飛び飛び）。
- チェック役としての判断：Spotifyがある公演には、YouTube Musicも揃える方向がよい。理由は2つ。(1)このアプリは調べ物・記録用で、有無の混在は利用者には「未完成」に見える（UNITE #01の分離をユーザーが指摘したのと同じ構図）。(2)日替わり曲が少ししか変わらないなら、近くの公演のプレイリストを土台に差分だけ直せば作れるので、負担は見た目より小さい。
- 例外：サブスク配信がないゲスト（マキシマム ザ ホルモン等）の公演は無理に揃えない。UNITE #02の6/22は、ユーザーが別途Claudeに伝えた通り「ホルモンのMVを外してB'zのサブスク曲だけ」が正解。
- 優先順位の提案：現行ツアーから。FYOP+の不足9公演、FYOPの不足6公演を先に。
